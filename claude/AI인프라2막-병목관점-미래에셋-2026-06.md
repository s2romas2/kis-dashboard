# AI 인프라 2막의 병목 — 관점 정리 (미래에셋증권 한종목, 2026-06-16, 86쪽)

> 원문: 미래에셋증권 Market Insight "AI Bottleneck Issue — 'AI 인프라 2막'의 병목". 2026-10-11 사용자 첨부본을 전부 읽고 Claude가 자기 말로 정리함.
> 사용자 지시: "어떤 기업이 좋다가 아니라 **어떤 이유에서 그 기업을 봤는지**가 중요. 병목의 여러 현상을 잘 봐둘 것."
> 숫자의 성격: 이 문서의 수치는 모두 **리포트가 인용한 값**(회사 발표·증권사 추정·업계 보도)이며 Claude가 따로 검증하지 않았다. "전해진다"로 쓴 것은 리포트도 보도·전언으로 다룬 미확인 정보다. 기준 시점은 2026년 6월이다.

## 1. 한 줄 요지

AI 인프라 1막은 "AI 관련주를 통째로 사면 되는" 시장이었고, 2막은 같은 이름표를 단 종목끼리 수익률이 갈리는 시장이다. 그래서 테마가 아니라 **AI 시스템이 만들어지려면 반드시 지나가야 하는 길목(병목)을 누가 쥐고 있는지**를 노드 단위로 나눠 봐야 한다. 리포트의 표현으로는 다음 초과수익이 "GPU 옆이 아니라 GPU 아래"에서 나온다.

## 2. 걸러내는 잣대 두 개

| 잣대 | 묻는 것 | 통과 못 하면 |
|---|---|---|
| ① 3축 평가 | 가격 전가력(원가 상승·공급 부족을 고객에게 넘기는가) / 낮은 대체 가능성(갈아타려면 재검증·설계 변경이 얼마나 드는가) / 재무 검증(이야기가 매출·마진·수주·가이던스로 확인되는가) | 미래 그림만 그럴듯한 기업 |
| ② 공백 테스트 | 이 회사가 3개월 사라지면 공급망에 무슨 일이 생기는가 | 별일 없으면 병목이 아니라 단순 수혜주 |

무게를 두는 것은 **지금 실제로 부족한 것**과 **숫자로 증명되는 것**이다. 미래 아키텍처에 대한 기대는 옵션으로만 취급한다.

3층 지도: 1층 본진(엔비디아·TSMC·메모리 — 확실하지만 이미 알려짐) / 2층 구조적 신규 병목(핵심) / 3층 비대칭 옵션(실패 확률 높고 성공 시 큼 — 소액 분산).

## 3. 종목을 고른 "이유"의 유형 (가장 중요)

| 이유 유형 | 뜻 | 리포트의 사례 |
|---|---|---|
| A. 어느 쪽으로 가도 필요한 아래층 | 기술 경쟁의 승패와 무관하게 공통으로 쓰이는 재료·기판·검사 | NPO가 이기든 CPO가 이기든 InP 광원, Photonics-SOI 기판, 정렬·검사는 필요. 그래서 완제품(광모듈)보다 그 아래를 선호 |
| B. 순증인가 잠식인가 | 새 시장이 열릴 때 기존 매출이 깎이는지 | 광모듈·광원(Lumentum·Coherent)은 CPO로 새 매출이 생기지만 기존 플러그어블이 잠식됨. 기판·파운드리·본딩(Soitec·Tower·BESI)은 순수하게 추가 |
| C. 여러 병목·여러 노드에 걸침 | 일정이 밀리거나 표준이 바뀌어도 버티는가 | Infineon(GaN·SiC 둘 다, 여러 전압 단계), Semtech(구리·광모듈 내부·차세대 광학 모두). 반대는 단일 노드 베팅 Wolfspeed(고전압 SiC만)·Navitas(GaN만) |
| D. 양산으로 넘어가는 관문 | 좋은 기술이 대량 생산품이 되려면 통과해야 하는 수율·테스트 | FormFactor(웨이퍼 단계에서 빛과 전기를 함께 검사), Teradyne(광학 테스트를 반도체 자동 테스트 흐름으로). 공급량을 정하는 것은 성능이 아니라 수율이라는 관점 |
| E. 한번 들어가면 못 바꾸는 자리 | 교체 비용이 기간으로 드러나는가 | 리타이머 교체에 재검증 12~18개월(Astera), 장비 플랫폼 수명 5~15년·매출 40%가 소모품과 서비스(MKS) |
| F. 금액은 작은데 대체 불가 | 고객 원가에서 비중이 작아 가격 저항이 약하고, 공급자는 사실상 하나 | Soitec: 하이퍼스케일러가 CPO에 1달러 쓸 때 0.3~1.4센트만 닿지만 점유율 95% 이상, 마진 55% 이상 가능 |
| G. 단가와 수량이 함께 뜀 | 세대가 바뀔 때 개수와 개당 가치가 동시에 느는가 | 레이저 800G 4개 → 1.6T 8개 / Semtech 모듈당 약 8달러 → 3.2T에서 약 80달러 / CPO 기판 면적 50 → 200mm² / 랙당 전력 반도체 4천 달러(Hopper) → 12.3만 달러(Rubin Ultra) |
| H. 숫자가 가격·믹스에서 나옴 | 실적 상향의 원인이 물량이 아니라 단가인가 | Ibiden 전자부문 영업이익 가이던스 570억 → 750억 엔, 그중 가격·믹스 +205억 엔, 물량 +15억 엔 |
| I. 가동률·유휴 시간을 지킴 | 부품값이 아니라 비싼 GPU가 서는 비용을 줄이는가 | 링크 하나가 깜빡이면 묶인 GPU 수천 개가 기다림(Credo), 신호 지연이 줄면 AI 팩토리 가동률이 오름(Semtech) |

→ 네오티스 블로그 글의 논리(P·Q 동시 상승, 원가 비중이 작아 가격 전가 쉬움, 초과수요를 받는 증설)와 F·G·H가 같은 뼈대다. 이 리포트가 더한 것은 **A(아래층), B(순증·잠식), C(노드 분산), D(양산 관문)** 네 가지다.

## 4. 병목이 진짜일 때 나타나는 현상 (점검표)

**가격·공급 쪽**
- 가격은 올리는데 투자는 줄임: TI 설비투자 강도 2024~25년 30% 안팎 → 2026년 13.3%. 과거 과잉투자의 기억 때문에 증설 대신 인상을 택함
- 경쟁사가 아예 철수: Renesas가 SiC를 접고 Wolfspeed에서 조달. 떠난 회사의 수요는 남은 소수에게 넘어감
- 동시다발 인상: TI·ADI·STM·NXP·Infineon이 2026년 상반기 줄줄이 인상(품목에 따라 5~35%)
- 마진이 눈에 띄게 뜀: 전력 설비 4~6% → 20~23%, CW 레이저 매출총이익률 81~87%로 알려짐

**주문·납기 쪽**
- 리드타임 연장(26주), 백로그 5~6년, 여러 곳에 같은 물량을 넣는 더블 부킹, 필요량보다 많이 사 두는 오버프로비저닝, 기술 검증을 건너뛰고 곧장 견적 요청
- 장기계약으로 완판되고 공급자가 고객을 고름: Lumentum은 출하가 수요보다 30% 이상 부족하다고 밝힘, EML 캐파는 2027년 말까지 사실상 배정
- 고객이 공급사에 돈을 먼저 넣음: 엔비디아가 Lumentum·Coherent에 각 20억 달러 투자하고 우선 공급권 확보
- 증설해도 모자람: InP 레이저를 2030년까지 12배 늘려도 수요의 약 50% 부족 추정 / AAOI는 2년간 생산능력을 9~10배 늘리는데도 2027년 중반까지 초과수요

**사슬 아래로 번지는 쪽**
- 채찍 효과: 최종 수요 +10% → GPU 주문 +15~20% → 웨이퍼 예약 +25~30% → 장비 주문 +35~40% → 장비 속 부품 +50~60%. 아래로 갈수록 증폭
- 주문이 매출보다 먼저 움직임: VAT 수주 +47%·수주/매출 1.6배, Ichor는 매출보다 재고·운전자본이 먼저 증가
- 병목이 옆으로 밀려남: 첨단 패키징이 모자라니 연결 일부가 보드로 밀려 고속 PCB·기판이 타이트해짐 / 랙 전력이 모자라 GPU를 두 랙으로 나누면 그 사이 1~3m 구리 연결 부품이 새로 필요해짐
- 다른 업종의 공급망을 끌어다 씀: 800V 전력 기술은 전기차·태양광에서 온 것. 전방이 죽어 있던 업종이 AI 수요로 살아남
- 가장 변두리까지 번짐: 유리섬유 같은 기초 소재(Unitika)까지 — 병목이 어디까지 내려가는지를 보여 주는 신호

**돈의 움직임 쪽**
- 비싼 인수: ADI가 매출 약 5,400만 달러 회사(Empower)를 15억 달러에 인수(매출의 약 28배)
- 옆 분야 강자가 지분을 삼: 광학 검사 강자 Onto가 X선의 Rigaku 지분 27% 확보 — 스스로 만들기 어렵다는 방증
- 지정학: 중국의 InP 수출 허가 통제. 증설과 별개로 국경을 넘을 수 있느냐가 변수가 되고, 같은 수혜주 안에서도 조달 지역에 따라 갈림

**물리 법칙 쪽 (왜 피할 수 없는가)**
- 전력: 600kW 랙을 48V로 주면 12,500A, 800V면 750A. 손실은 전류의 제곱에 비례
- GPU 바로 앞: 전압은 0.7V 안팎으로 고정인데 전력이 커져 전류가 3,300A까지 — 변환기를 칩 아래로 내려야 함
- 신호: 속도가 오를수록 구리에서 손실·간섭 급증 → 거리에 따라 구리와 광학이 영역을 나눔
- 수율: 광엔진 하나 95%여도 32개가 한 패키지면 19% — 분리·교체 가능한 구조가 유리한 이유
- 검사: 결함이 표면에서 내부로 숨음(GAA·후면 전력·적층) → 광학에서 X선으로

## 5. 걸러야 할 것

| 걸러야 할 것 | 내용 |
|---|---|
| 바스켓으로 묶는 사고 | "전력 반도체", "광통신주", "CPO 수혜주"는 하나가 아님. 같은 650V 등급에서도 SiC만/GaN만/둘 다 만드는 회사가 갈림. 엔비디아 800V 보드에 11개사가 서로 다른 부품을 냄 — 표준 승자가 아직 없음 |
| 한 줄짜리 서사 | "CPO가 구리를 죽인다", "GaN이 SiC를 이긴다"는 틀림. 실제는 거리별·전압별 역할 분담 |
| 시간표를 무시한 기대 | 지금 돈이 되는 것(가격 인상 사이클, 800G·1.6T, InP 부족)과 2028년 이후 옵션(800V 본격화, SST, CPO 대량 매출)을 구분 |
| 단일 노드·단일 일정 의존 | 방향이 맞아도 일정이 밀리면 받쳐 줄 다른 매출이 없음(Wolfspeed·Navitas) |
| 병목을 소유하지 못한 중간자 | 전력만 있고 냉각·네트워크·서비스 보증이 없는 GPU 임대업(위는 엔비디아, 아래는 대형 고객에 끼임). 중간 조립업은 가치가 표준 플랫폼으로 흡수되면 마진 35~40% → 10~15% 위험 |
| 자기잠식 | 새 구조가 기존 주력 매출을 깎는 회사 |
| 이미 가격에 들어간 것 | Semtech 12개월 선행 PER 약 50배, Credo 급등 — 리포트도 인정 |
| 회사 설명에만 기대는 효과 | Credo Zero-Flap은 독립 검증 데이터가 더 필요 |
| 과장 | 인텔 EMIB는 TSMC를 대체하는 기술이 아니라 CoWoS가 모자랄 때의 두 번째 공급원. SST도 모든 변압기를 대체하는 것이 아님 |
| 수요가 강하다 = 좋은 주식 | 리포트의 결론 문장. 테마 노출이 아니라 병목 소유를 볼 것 |

## 6. 세 병목과 시간표

| 병목 | 지금(2026~27) 돈이 되는 것 | 2028년 이후 옵션 |
|---|---|---|
| 전력 | 아날로그·전력 반도체 가격 인상, 변압기·배전 설비 공급자 우위, 과도기 구조(400V DC, 랙 옆 HVDC 장비, 배터리·슈퍼커패시터) | 800V DC 본격 채택(2028년 2~3분기부터), DC 차단·감시 장비, SST(2029년 전후), 칩 아래 전력 변환 |
| 통신 | 800G → 1.6T 플러그어블, NPO, InP 광원 부족(2027년 상반기까지 매우 빠듯, 2028년 3분기쯤 균형), 짧은 거리의 구리·아날로그 보정 | 2.5D CPO 본격화(2028~29), 3D CPO(2030 전후) |
| 제조 | 장비 속 부품(RF·플라즈마·진공·레이저·도금), 하이브리드 본딩, 양산 테스트, 고속 기판 | X선 검사의 양산 진입, 패널 기반 대형 패키지 |

800V 전환 4단계: ① 기존 교류 유지 + 랙 옆 직류 장비(비용은 오히려 증가) → ② 800V가 서버 블레이드까지 → ③ 홀 전체 직류 배전(직류는 끊기 어려워 차단·감시 장비가 새 시장) → ④ SST. 단계마다 수혜 품목이 다르다.

CPO 종목 선별 5관문: TSMC 플랫폼 편입 / 대형 고객 인증 / 마지막 정렬·열 문제 해결 / 양산 테스트 자동화 / 수율이 매출·마진으로 확인.

- 정예 8종 안에서도 재무 검증 수준이 고르지 않음: Soitec은 매출 -26%로 성장률+이익률 합이 마이너스. "구조적으로 가장 비대칭"이라는 논리로 넣은 것
- 작성자가 MKS 주식 7주 보유(리포트 고지)
- 해외 종목 중심. 국내 소부장에 그대로 옮길 수 있는 것은 종목이 아니라 3·4·5절의 이유와 현상

## 9. 대시보드 작업과의 연결 (메모)

- 반도체 peer 상대밸류의 "기준 peer로 본 상단" 칸에서 **깎을 요소 후보**로 쓸 수 있는 것: 단일 노드·단일 일정 의존, 기존 매출 잠식, 고객이 쉽게 갈아탈 수 있는지, 숫자 확인 전 단계인지
- 국내 소부장을 다시 볼 때의 질문: 3개월 사라지면 누가 멈추는가 / 가격을 올리고 있는가, 증설은 초과수요 대응인가 / 세대 전환 때 개수와 단가가 함께 느는가 / 고객 인증 교체에 얼마나 걸리는가 / 실적 상향이 물량이 아니라 가격·믹스에서 나오는가
- 광통신 쪽은 프로젝트의 기존 문서(`claude/광통신-…` 시리즈)와 겹침 — InP·CW 레이저·정렬 병목 관점이 같은 방향
