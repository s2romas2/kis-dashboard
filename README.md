# 한국 GICS 섹터 실시간 대시보드 (KIS 오픈API)

한국투자증권(KIS) 오픈API로 **국내주식 실시간 시세**를 받아, GICS 11개 섹터별 시총 상위 10종목을
시가총액순·거래량순으로 보여주는 대시보드입니다. 브라우저는 KIS를 직접 못 부르므로(CORS·인증),
작은 **중계 서버**(`server.js`)가 인증키를 쥐고 시세를 대신 받아 화면에 전달합니다.

```
kis-dashboard/
├── server.js          ← 중계 서버 (Node.js, 외부 패키지 없음)
├── package.json
├── .env.example       ← 인증정보 양식 (복사해서 .env 로 저장)
└── public/index.html  ← 대시보드 화면
```

---

## 1단계 — KIS 오픈API 키 발급 (최초 1회)

1. **한국투자증권 계좌**가 필요합니다(없으면 비대면 개설).
2. KIS Developers 포털 접속 → https://apiportal.koreainvestment.com
3. 로그인 후 **[신청/변경] → 오픈API 신청**에서 사용 신청.
4. 계좌를 등록하고 **APP KEY / APP SECRET**을 발급받습니다.
   - 실시간 시세를 쓰려면 **실전투자** 계좌의 키를 사용하세요(모의투자는 시세가 제한적).
5. 발급받은 APP KEY / APP SECRET 두 값을 복사해 둡니다.

> ⚠️ 이 키는 비밀번호와 같습니다. 절대 화면(프론트엔드)이나 깃허브 공개 저장소에 넣지 마세요.
> 반드시 서버 환경변수(.env)로만 보관합니다. 이 구조가 그래서 필요한 겁니다.

---

## 2단계 — 내 컴퓨터에서 실행해 보기

1. **Node.js 18 이상** 설치 (https://nodejs.org — LTS 버전). 설치 확인: 터미널에서 `node -v`
2. 이 폴더에서 `.env.example` 을 복사해 **`.env`** 파일로 만들고 값을 채웁니다:
   ```
   KIS_APPKEY=발급받은_APP_KEY
   KIS_APPSECRET=발급받은_APP_SECRET
   KIS_ENV=real
   PORT=3000
   ```
3. 터미널에서 이 폴더로 이동 후 실행:
   ```
   node server.js
   ```
4. 브라우저에서 **http://localhost:3000** 접속 → 섹터를 클릭하면 실시간 TOP10이 뜹니다.

여기까지 되면 데이터 연동은 성공입니다. 단, `localhost`는 내 컴퓨터에서만 열려서
**다른 사람과 공유하려면 3단계(배포)가 필요**합니다.

---

## 3단계 — 공유용 링크로 배포하기 (선택)

다른 사람이 링크로 접속하게 하려면 서버를 인터넷에 올려야 합니다. 무료로 시작할 수 있는 예시:

### 방법 A — Render.com (가장 쉬움)
1. 이 폴더를 GitHub 저장소에 올립니다. (**단, `.env` 와 `.kis_token.json` 은 올리지 마세요.** `.gitignore`에 추가)
2. https://render.com 가입 → **New → Web Service** → 해당 GitHub 저장소 선택.
3. 설정: Build Command `(비움)`, Start Command `node server.js`.
4. **Environment** 탭에서 `KIS_APPKEY`, `KIS_APPSECRET`, `KIS_ENV=real` 를 추가(여기가 키 보관 장소).
5. 배포되면 `https://내앱이름.onrender.com` 링크가 생깁니다. 이 링크를 공유하세요.

### 방법 B — Railway / Fly.io / 개인 서버(VPS)
- 동일하게 환경변수로 키를 넣고 `node server.js`를 상시 실행하면 됩니다.

> 무료 플랜은 일정 시간 미접속 시 잠들었다가 첫 접속에 몇 초 지연될 수 있습니다.

---

## 알아두면 좋은 점

- **실시간성**: KIS 국내주식 현재가는 실시간에 가깝습니다(미국 무료 API의 15~20분 지연 문제 없음).
- **시가총액**: KIS가 주는 값(`hts_avls`, 억원)을 그대로 사용합니다.
- **자동 갱신**: 화면은 한국장 시간대(08:00~18:00)에 60초마다 자동 갱신됩니다. 그 외 시간엔 '장마감' 표시.
- **접근토큰**: 서버가 24시간짜리 토큰을 자동 발급·갱신하고 `.kis_token.json`에 캐시합니다.
- **호출 제한**: KIS는 초당 호출 제한이 있어 서버가 종목을 순차 조회합니다. 한 섹터(10종목)는 수 초 내 로딩됩니다.
- **섹터 매핑**: 한국은 GICS와 정확히 맞아떨어지지 않아(특히 에너지·유틸리티·부동산·2차전지) 대표기업을 합리적으로 배정했습니다. 종목을 바꾸려면 `public/index.html` 의 `KTOP10` 목록을 수정하면 됩니다.

## 문제 해결
- `토큰 발급 실패` → APP KEY/SECRET, KIS_ENV(real/mock)이 맞는지, 오픈API 사용 신청이 승인됐는지 확인.
- `Node 18 이상 필요` → `node -v`로 버전 확인 후 최신 LTS 설치.
- 종목이 '실패'로 뜸 → 해당 종목코드가 상장폐지/거래정지거나 시장구분이 다를 수 있음.
