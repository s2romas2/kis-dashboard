# 밸류 워크시트 리서치 절차 (종목 1개를 "조사해서 채운" 상태로 만드는 순서)

2026-10-12 작성. 계기: 엑시콘을 워크시트에 넣었더니 산업 TAM도, 삼성 수주도 없는 빈 초안이 나옴.

## 왜 이 절차가 필요한가

- 워크시트는 **리서치 시드(`public/data/valws_seed.json`)가 있는 종목만** 내용이 있다. 시드가 없으면 `makeDraft()`가 최근 4분기 매출·이익률을 1.5년 늘린 값만 넣는다. TAM·수주·가시성은 빈칸.
- "공시에 없으면 공신력 있는 외부자료를 응용한다"는 규칙은 **사람(Claude)이 시드를 만들 때만** 적용된다. 수집기(`valws.py`)는 시세·컨센서스·재무제표·CB/BW만 읽고, 공급계약 공시·수주상황·증권사 자료는 읽지 않는다.
- 그래서 종목을 새로 볼 때는 아래 순서로 조사해 시드를 써야 한다. 화면의 "리서치 n/7" 배지가 7이 될 때까지.

## 자동으로 채워지는 것과 사람이 조사할 것 (2026-10-12 추가)

| 구분 | 내용 | 어디서 |
|---|---|---|
| 자동(매일) | 공급계약 공시(품목·금액·상대방·기간·정정), 정기보고서의 제품 비중·매출실적·수주상황·가동률 표, 수주잔고 | `valfacts.py` → `public/data/vf/<코드>.json` |
| 자동(매일) | 최대주주·특수관계인, 배당 3년, 보수, 자기주식, 5% 주주, CB·BW·EB·유증, 자동 경고 | 같은 파일의 `gov`·`dec`·`maj`·`flags` |
| 자동(매일) | 경영진·지배구조 뉴스 반복 언급(주제별 건수·제목·링크, 미검증) | 같은 파일의 `news` |
| 자동(매일) | FY1 컨센서스, 증권사 리포트 목록 | 같은 파일의 `annual`·`rpt` |
| 조사 후 고정 | 세부분야 TAM(61개 그룹) | `valws_tam.json` — 전망이 갱신되면 다시 조사 |
| **사람 조사** | 매출을 제품별 수량×단가로 나누기, 단가 역산, 성장 지속기간, PER 범위와 근거, 고객사 투자와의 연결 | `valws_seed.json` |
| **사람 조사** | 자동 경고와 뉴스 제목을 읽고 사실·보도·의혹으로 정리, 특수관계자 거래·담보·제재(본문에만 있음) | `valws_gov.json` |

- 자동 초안은 판정을 보류한다(가시성 "조사 전"). 시드를 쓰면 판정이 나온다.
- 시드를 쓸 때는 먼저 `vf/<코드>.json`을 읽는다 — 공급계약·수주잔고·제품 비중·컨센서스가 이미 들어 있다.

## 경영진 이야기는 사실 확인이 안 돼도 기록한다 (사용자 지시, 모든 기업)

- 뉴스·소식지에서 계속 언급되는 경영진 이야기(승계, 주가 누르기, 주주환원, 보수, 주주와의 갈등 등)는 **팩트체크가 안 되더라도 반드시 체크해 적는다.** 태그는 `의혹`.
- 적는 내용: 누가(매체·주주·업계 관계자) 무엇을 근거로 말했나 / 공시로 확인되는 부분과 안 되는 부분 / 회사 입장 / 앞으로 사실 여부를 가를 신호.
- **"보도 없음"이라고 쓰려면 키워드 뉴스 검색을 먼저 돌린다.** 회사명 + 승계·증여·상속·주가 누르기·주주환원·행동주의·소액주주·보수·주총·횡령·배임. 기사 몇 개만 열어 보고 단정하지 않는다(월덱스에서 이렇게 틀렸다 — 에너지경제 6/28 기사를 놓침).
- 자동 수집기의 `news.items`가 이 검색을 매일 대신한다. 조사 기록을 쓸 때는 이 목록에서 승계·증여, 사고·제재, 주주행동 기사를 본문까지 읽는다.

## 조사 순서 (위에서부터, 근거가 강한 것 먼저)

| 단계 | 볼 자료 | 채우는 칸 | 태그 |
|---|---|---|---|
| 1 | DART **단일판매·공급계약체결**(최근 2년, 정정 포함) | 제품별 Q의 바닥, 고객, 납기, 판매지역 | 확인 |
| 2 | 최근 정기보고서 **II. 사업의 내용** — 수주상황(수주총액·기납품·잔고), 제품별 매출 비중, 주요 고객 비중, 생산능력·가동률 | 수주잔고, 제품 행 나누기, CAPA, 고객 집중 | 확인 |
| 3 | 분기 실적(hege) — 분기 매출과 이익률의 관계 | OPM Base/Bear/Stress(매출 규모별 실제 이익률) | 확인→역산 |
| 4 | 단가: 공시에 대수가 없으면 **계약금액 ÷ 보도된 대수**로 역산, 보도 단가와 맞는지 검산 | ASP | 역산 |
| 5 | 증권사 리포트(요약 기사 포함) — 대상연도 매출·영업이익, 제품별 추정, 목표 PER | Base 매출 맞추기, PER 범위 | 증권사 |
| 6 | 고객사 투자: 고객 공시·IR, 통신사(로이터 등) 보도 — 공장·금액·가동 시기 | TAM의 "이 회사가 실제로 파는 시장", 지속기간 | 보도 |
| 7 | 글로벌 1위 업체 IR(시장 규모 추정) | TAM 상단 숫자 | 회사발언 |
| 8 | 경영진 체크 7항목(아래) | `valws_gov.json` | 확인/보도/판단/의혹 |

## 원칙

- **확인된 것과 기대를 섞지 않는다.** 예: 엑시콘 "베트남향"은 수주 공시가 아직 없다(공시된 계약의 판매지역은 모두 대한민국). 베트남 물량은 보도·증권사 추정으로 따로 적고 Base에는 가동 시기 이후 분만 넣는다.
- Base는 증권사 추정에 맞추되, **어느 행이 증권사 1곳에 걸려 있는지** 메모에 적는다(엑시콘: SSD 테스터 1,260억 = Base 매출의 55%).
- Bear·Stress는 각각 출처가 있는 숫자로(직전 추정치, 올해 실적 연환산 등). 감으로 30% 깎지 않는다.
- 대상연도 수주 공시가 없으면 가시성 등급을 수동으로 3 이하로 둔다.
- 역산·가정은 공식과 링크를 반드시 남긴다(없으면 화면에서 '미확인'으로 강등됨).

## 경영진 체크 7항목

1. 최대주주·특수관계인 지분(계열사 지분 포함), 최근 변동
2. 승계: 자녀·손주 지분, 증여·장내매수, 가족 임원
3. 대표·등기이사 보수(보수 한도, 실적과의 방향)
4. 배당(배당성향·시가배당률)과 자기주식(취득·처분·소각, 처분 시점)
5. 특수관계자 거래·담보·보증(금액 추이, 같은 지배주주의 다른 상장사 여부)
6. 제재 이력(사업보고서 제재 현황)
7. 주총 운영·공시 태도(부결 안건, 전자투표, 정정 공시 반복)

- 사실(공시) / 보도 / 판단 / 의혹을 태그로 나눈다. 의혹은 "누가 제기했는지, 근거가 있는지"까지 확인하고, 못 찾으면 못 찾았다고 적는다.
- 미성년 특수관계인은 이름을 적지 않는다.

## 파일

- 시드: `public/data/valws_seed.json` → `map[code]` (필드는 기존 시드 참고, `updated`를 바꾸면 시드 상태인 브라우저에 다시 적용됨)
- 경영진: `public/data/valws_gov.json` → `map[code] = {sum, grade{}, items[{k,v,tag,lv,src[]}], todo[]}`
- 자동수집 대상: `public/data/valws_watch.json`의 `codes`·`peers`·`chain`·`anchors`
- 생성 스크립트 예: 엑시콘 `mk_exicon.py`(세션 작업 폴더) — 출처를 변수로 두고 시드·경영진 JSON을 한 번에 생성
